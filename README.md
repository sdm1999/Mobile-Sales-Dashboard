# Mobile Sales Dashboard

## Overview
This Power BI dashboard provides an end-to-end analysis of mobile sales performance, key metrics, and revenue trends.

## Features
- **Sales Performance:** Key metrics including total revenue, total quantity sold, and average transaction value.
- **Brand & Model Analysis:** Top-performing mobile brands, model popularity, and customer preferences.
- **Interactive Filtering:** Dynamic slicers to filter data by date, product type, and category.

## Files Included
- `MS_Dashboard.pbix`: The main interactive Power BI report file.

## How to View
1. Download the `MS_Dashboard.pbix` file from this repository.
2. Open the file in **Power BI Desktop** to view and interact with the report.
